About this private demo

New accounts need email confirmation. Open the private inbox supplied with this app, follow the link, then return to sign in. Please don’t repeatedly register an address while waiting for confirmation.

Signing out ends this device’s refresh session. Server-wide sign-out cannot be confirmed, and issued access tokens may remain valid until expiry. Accounts and tasks are deleted when this disposable server shuts down. Use separate browser profiles for independent users; live cross-tab session synchronization is not supported.
