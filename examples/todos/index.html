About this private demo

New accounts need email confirmation. Open the private inbox supplied with this app, follow the link, then return to sign in. Official TrailBase 0.35.8 returns no signup user/session. A repeated pending registration can return HTTP 409, and this app has no confirmation resend or account repair. Please don’t repeatedly register while waiting for confirmation.

Signing out clears local state and requests this device’s refresh-session revocation; failures remain visible. Server-wide sign-out cannot be authenticated as successful, and issued access tokens may remain valid until expiry. Accounts and tasks are deleted when this disposable server shuts down. Use separate browser profiles for independent users; live cross-tab session synchronization is not supported.
